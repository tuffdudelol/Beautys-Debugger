# Beautys-Debugger
Roblox debugging script (Animation logger, Sound logger, Dex, Remote spy, Http spy.)
If you dont know what any of those things are, let me tell you.
So an http spy will basically log any urls that are called to (i dummed this down alot)
An animation logger will log the id's of animations that play.
A sound logger will log the sound effects that play.
Dex is basically a roblox script that brings the Explorer tool and Properties tool from roblox studio ingame, its very good for making scripts.
Remote spy basically detects any remotes ran, and gives you the code for them, along with various other buttons.
And beauty, includes all of these! (all of them made by beauty besides dex lol, i aint makin dex.)
